题目背景

题目描述

DYYqwq 在网络最大流模板中套取数据以抢最优解这个工单的责任人被转来转去，小 F 都不知道现在的责任人是谁了。。。

初始时 chen_zhe 是这个工单的责任人。

现在给出 n 个二元组 (ti, si)，表示在 ti 时刻责任人被转成了名字为 si 的管理员。

有 q 次询问：每次询问给出一个 x，求在 x+0.5 时刻的责任人。

假设转责任人可以不需要时间。

输入格式

第一行，两个正整数 n,q。
接下来 n 行，每行一个二元组 (ti, si)。
接下来 q 行，每行一个数 x，表示一次询问。

输出格式

对于每个询问，一行输出答案。

说明/提示

1 ≤ n, q, Σ|si| ≤ 105, 1 ≤ ti ≤ 109。

保证 si 只由大小写字母和下划线组成。

提示

请注意，如果 x 时刻之前没有责任人变更，那么责任人仍然是初始的 chen_zhe。
