二分答案

在答案具有单调性的前提下，利用二分的思想枚举答案，将求解问题转化为验证结果。首先估计答案的上下界，然后不断取区间中点进行验证，通过验证结果不断更新答案区间，最终得到答案。

注本条目特指“二分答案”这一解题策略，不包括二分查找（在有序数组中查找特定元素）。

倍增（含普通倍增 LCA）

预处理以 2 的整次幂为步长的状态，再把任意目标步数按二进制拆成若干 2 的幂之和，逐段跳跃合并出答案。该思想是 ST 表与最近公共祖先（LCA）的基础，也用于求树上第 k 级祖先一类可倍增合并的问题。

折半搜索

从状态图上的起点和终点同时开始进行搜索，或将搜索分成多半分别搜索，最后合并。通过将搜索空间一分为二（或多份）分别枚举，再合并两半（或多份）的结果来降低时间复杂度。

注注意：此处的“折半搜索”指 meet-in-the-middle，与二分查找（binary search / half-interval search）是不同的概念。

哈希

将输入（如字符串、集合等）映射到一个值域较小、可以方便比较的范围的映射函数。在算法竞赛中，通常采用多项式哈希的方法。哈希函数的核心性质是：哈希值不同则原输入一定不同；哈希值相同则原输入大概率相同（存在哈希碰撞的可能）。

Trie 树

通过节点代表从根节点到该节点的路径上的信息的树形数据结构。每个节点代表一个字符串（从根到该节点的路径），从根节点出发沿字符边可到达所有前缀。

KMP

KMP算法是所有字符串匹配算法的集合中，唯一满足以下正交约束的算法：（1）预处理生成最长边界闭包；（2）扫描阶段文本指针绝对单增；（3）失配转移函数等于边界函数的Kleene闭包；（4）匹配后保留边界重叠。

¥ 50

AC自动机

以 Trie 树中的失配链代替 KMP 中的序列做多模式字符串匹配的算法/数据结构。通过构造一个有限状态机（在 Trie 树中添加失配指针），允许在匹配失败时回退到某前缀的其他分支，免于重复匹配前缀。

注此类不算 KMP / Trie。

SAM

后缀自动机（SAM） 是字符串上的唯一最小 DFA，其状态集合由 endpos 等价关系严格商掉所有子串得到。它必须携带双重结构——转移函数和后缀链接函数。其在线构造算法强制要求执行“克隆”操作以维持状态数 |Q| ≤ 2|S| − 1 的紧界。

高斯消元

它在数域 F 上对增广矩阵施加有限序列的初等行变换（行交换、行缩放、行加法），并在每列执行带部分主元（行交换）的前向消去，将矩阵唯一（在归一化后）地转化为行阶梯形（REF），随后必须通过从底向上的严格回代过程输出解向量。

并查集

通过树形结构维护元素间是否在同一集合的数据结构。支持三种基本操作：初始化（每个元素自成集合）、查找（Find，确定元素所属集合的根节点）、合并（Union，将两个不同集合联结）。常配合路径压缩与启发式合并两种优化策略。

本条目不包括分块的思想及应用此思想的其他算法，特指：（1）块状数组：将序列分成若干块，在每块上分别维护信息；（2）块状链表：每个节点下挂着一个线性链表，维护一段区间。

莫队

将询问按照左端点所在块为第一关键字、右端点为第二关键字排序，通过维护两个指针在序列上移动来回答所有区间询问。通过合理地分块和排序，使指针移动的总次数达到 O((n+q)√n) 的级别。

单调栈

维护一个栈内元素单调递增或单调递减的栈结构。每个元素入栈时弹出所有破坏单调性的元素，从而在 O(n) 时间内求解每个元素左侧/右侧第一个比它大/小的元素等问题。

单调队列

维护一个队首到队尾单调递增或单调递减的双端队列。常用于滑动窗口最值问题，每个元素入队时从队尾弹出破坏单调性的元素，从队首获取当前窗口的最值，时间复杂度 O(n)。

ST 表

基于倍增思想的静态区间最值查询数据结构。预处理 st[i][j] 表示从 i 开始长度为 2^j 的区间的最值，查询时将区间 [l, r] 拆分为两个长度均为 2^k 的区间（k = ⌊log₂(r-l+1)⌋）取最值，单次查询 O(1)。仅支持静态查询，不支持修改。

¥ 60

树状数组

一种专为区间统计设计的高效数据结构，修改和查询的时间复杂度均为 O(log N)，代码量小、常数小。通过二进制拆分区间维护前缀信息，支持单点修改和区间查询（查询需满足可减性，如区间和）。核心操作基于 lowbit 实现。

线段树

一种基于分治思想的二叉树数据结构，每个节点代表一个区间，维护该区间的某种信息（如和、最大值、最小值等）。支持区间修改和区间查询，时间复杂度均为 O(log N)。通过懒标记（Lazy Tag）可实现区间加、区间赋值等操作。

平衡树

一种自平衡的二叉搜索树，通过旋转等操作保持树的高度为 O(log N)，从而保证插入、删除、查找、前驱/后继、排名查询等操作的时间复杂度均为 O(log N)。常见实现有 Treap、Splay、FHQ-Treap、红黑树等。

笛卡尔树

一种特殊的二叉树，其中序遍历对应原序列的顺序，且满足堆性质（大根堆或小根堆）。每个节点的键值为原序列中的值，优先级为下标（或反之）。可通过单调栈在 O(n) 时间内构建，常用于 RMQ 问题的转化。

树链剖分

将树分解为若干条不相交的链（重链/轻链），使得树上任意两点间的路径可以被分解为 O(log N) 条链上的区间。结合线段树等数据结构，可支持树上路径修改、路径查询、子树修改、子树查询等操作，单次操作时间复杂度 O(log² N)。

¥ 50

虚树

在原树中只保留若干关键节点及其两两之间的 LCA，并重新构建一棵压缩后的树。虚树保留了关键节点之间的祖先关系和路径信息，节点数为 O(k)（k 为关键节点数），常用于处理与关键节点相关的树上问题，避免遍历整棵树。

¥ 60

树分治

利用树的重心或点分治、边分治等策略，将树上的问题分解为经过某个中心节点和不经过该中心节点两类子问题，递归处理。常见的有点分治（处理路径统计问题）和边分治。时间复杂度通常为 O(N log N) 或 O(N log² N)。

¥ 30

拓扑排序 / DAG

对有向无环图（DAG）的所有顶点进行线性排序，使得对于每一条有向边 (u, v)，u 在排序中都出现在 v 之前。可通过 Kahn 算法（不断删除入度为 0 的节点）或 DFS 实现。常用于判断图是否有环、求解 DAG 上的最长路/最短路、依赖关系处理等。

¥ 60

最短路 / 差分约束

最短路：在带权图中求两点之间的最短路径。常见算法包括 Dijkstra（非负权，O((N+M)log N)）、Bellman-Ford（可处理负权，O(NM)）、SPFA（队列优化 Bellman-Ford）、Floyd（全源最短路，O(N³)）。

差分约束：将形如 x_i − x_j ≤ c 的不等式组转化为图论中的最短路问题。对每个不等式建边 j → i 权值为 c，若图中有负环则无解，否则最短路给出可行解。

¥ 50

生成树算法

在无向连通图中求一棵包含所有顶点的树，使得边权之和最小（最小生成树，MST）。常用算法有 Kruskal（基于并查集，按边权排序后从小到大加边）和 Prim（基于优先队列，从某点开始扩展）。时间复杂度分别为 O(M log M) 和 O((N+M)log N)。

¥ 50

强连通分量

在有向图中，如果两个顶点互相可达，则称它们强连通。强连通分量（SCC） 是极大的强连通子图。常用 Tarjan 算法或 Kosaraju 算法在 O(N+M) 时间内求出所有 SCC。缩点后得到 DAG，可用于解决 2-SAT、传递闭包等问题。

27
¥ 50

边双连通分量

在无向图中，若去掉任意一条边后图的连通性不变，则称该图为边双连通的。边双连通分量（边双） 是极大的边双连通子图。可通过 Tarjan 算法求桥（割边），删去所有桥后每个连通块即为一个边双连通分量。

¥ 60

点双连通分量 / 圆方树

点双连通分量（点双）：在无向图中，若去掉任意一个顶点后图的连通性不变，则称该图为点双连通的。极大的点双连通子图称为点双连通分量。两个点双至多共享一个顶点（割点）。

圆方树：将原图的每个点作为圆点，每个点双连通分量作为方点，在方点和属于该点双的所有圆点之间连边，形成一棵树。圆方树将图上的问题转化为树上的问题，常用于处理仙人掌图、动态图连通性等。

网络流

研究有向图中从源点到汇点的流量分配问题。核心是最大流（在容量限制下从 s 到 t 的最大流量），常用算法有 Dinic（O(N²M)）、ISAP、HLPP 等。最小割是最大流的对偶问题。费用流在最大流基础上增加单位流量费用，求最小费用最大流，常用 SSP（SPFA 增广）、Dinic + 势能（Primal-Dual）等。

凸包

插头 DP

一种基于连通性状态压缩的 DP。在网格图上逐格转移，使用括号表示法或最小表示法记录已处理格子的连通性状态。常用于格点图的哈密顿路径/回路计数、棋盘染色方案计数等。

注此类属于状压 DP 的子类。

斜率优化 DP

针对形如 dp[i] = min/max { dp[j] + a[i]·b[j] + c[i] } 的 DP 转移方程，将决策点 (b[j], dp[j]) 视为平面上的点，用单调队列维护凸包（下凸包求最小值，上凸包求最大值），将 O(N²) 的转移优化到 O(N)。要求斜率（决策点之间的斜率）具有单调性。

线性规划

在一组线性不等式（约束条件）的约束下，求解线性目标函数的最大值或最小值。标准形式为 max c^T x s.t. Ax ≤ b, x ≥ 0。常用算法有单纯形法（实践中高效，但最坏情况指数级）和内点法（多项式时间）。在算法竞赛中通常指单纯形法及其变体。

分数规划

求解形如最大化（或最小化）Σ a_i / Σ b_i 的比值优化问题。常用二分答案 + 判定（将原问题转化为 Σ (a_i − mid·b_i) ≥ 0 的判定问题）。常见于最优比率生成树、最优比率环（01分数规划）等问题。

线段树合并 / 分裂

线段树分裂：将一棵权值线段树按值域分裂为两棵，用于维护可分裂的集合（如区间操作中的分离）。常用于珂朵莉树的替代、可持久化可分裂线段树等。

李超线段树

一种维护线段（或直线）集合的数据结构，支持插入一条线段/直线，以及查询在某个 x 坐标处所有线段中的最大值/最小值。每个节点维护一条在该节点区间中点处取值最优的线段，插入时与子节点比较并下放，查询时沿根到叶子的路径取最值。时间复杂度 O(log² N)（线段插入）或 O(log N)（直线插入）。

猫树

一种支持静态区间查询（可重复贡献问题，如区间最值、区间 gcd 等）的数据结构。通过分治预处理每个区间中点向左右扩展的信息，查询时找到 l 和 r 所在子树的分治中点，O(1) 合并左右信息。预处理 O(N log N)，查询 O(1)。

可持久化线段树

在普通线段树的基础上，每次修改时创建新版本，保留旧版本的所有信息（即“可持久化”——可访问历史版本）。每次修改只新建被修改的 O(log N) 个节点，其余节点复用旧版本的节点。支持在任意历史版本上查询和修改。常见应用包括静态区间第 k 小（主席树）。

树套树

LCT 及其他动态树

Link-Cut Tree（LCT）：一种支持动态森林维护的数据结构，支持加边（Link）、删边（Cut）、换根（Makeroot）、路径查询/修改等操作，所有操作均摊 O(log N)。基于实链剖分和 Splay 实现。

其他动态树：包括 Top Tree（支持更一般的动态树操作）、ETT（欧拉游览树，支持子树操作）等。本条目涵盖所有支持动态加边/删边并维护树上路径信息的树形数据结构。

珂朵莉树

一种基于 std::set 的暴力数据结构，将值相同的连续区间合并为一个节点（区间赋值操作）。仅适用于数据随机或带有区间赋值操作（assign）的场景，最坏情况下时间复杂度可能退化为 O(N²)，但在随机数据下表现良好。核心操作是 split(pos) 将包含 pos 的区间分裂。

快速幂

快速计算底数的 n 次幂的算法，时间复杂度 O(log n)。核心思想是将指数 n 按二进制拆分为若干 2 的幂之和，通过反复平方底数并累乘对应项来得到结果。矩阵快速幂是将普通乘法推广到矩阵乘法，用于快速求矩阵的 n 次方。

模拟退火

一种基于物理退火原理的随机化全局优化算法。通过模拟固体退火过程中粒子逐渐趋于能量最低状态的过程，在搜索过程中以一定概率接受劣解，从而避免陷入局部最优。温度参数随时间逐渐降低，接受劣解的概率也随之减小。

爬山算法

一种简单的局部搜索算法。从当前解出发，不断向邻域中更优的解移动，直到无法找到更优解为止（到达局部最优）。容易陷入局部最优，通常作为其他算法的子过程或结合随机重启使用。

Z 函数（扩展 KMP）

后缀数组

将一个字符串的所有后缀按字典序排序后得到的数组，以及辅助的 rank 数组和 height 数组（LCP 数组）。常用倍增法或 DC3 算法在 O(N log N) 或 O(N) 时间内构建。结合 height 数组可高效解决最长重复子串、不同子串个数、最长公共子串等字符串问题。

2-SAT

判定是否存在一组布尔变量的赋值，使得所有给定的二元子句（形如 (a ∨ b) 或 (¬a ∨ b) 等）同时成立。通过将每个变量拆为真、假两个节点建图，利用 Tarjan 求 SCC 判定可行性，并在有解时构造一组解。时间复杂度 O(N+M)。

匈牙利算法

求解二分图最大匹配的经典算法。通过不断寻找增广路来增加匹配数，每次从一个未匹配的左部点出发，尝试为它找到一个可匹配的右部点，若冲突则递归调整。时间复杂度 O(VE)。
